# React Kit Documentation

Documentation site for [@js-smart/react-kit](https://www.npmjs.com/package/@js-smart/react-kit), built with [Docusaurus](https://docusaurus.io/docs).

## Local development

From the repository root:

```bash
pnpm install
pnpm start:docs
```

The site runs at [http://localhost:3008](http://localhost:3008).

## Build

```bash
pnpm build:docs
```

Static output is written to `apps/docs/build/`.

## Content structure

| Section | Path | Description |
| ------- | ---- | ----------- |
| Introduction | `docs/introduction/` | Overview and component index |
| Getting Started | `docs/getting-started/` | Installation and setup |
| Components | `docs/components/` | Component API and usage |
| Utilities | `docs/utilities/` | Utility function reference |
| Constants | `docs/constants/` | Shared app constants |

Docs are MDX files with autogenerated sidebar navigation via `_category_.json` files.

## Deployment

The site is deployed to [Netlify](https://js-react-kit.netlify.app/) via [`netlify.toml`](../../netlify.toml) at the repository root:

| Setting | Value |
| ------- | ----- |
| Build command | `pnpm build:docs` |
| Publish directory | `apps/docs/build` |

Netlify runs `pnpm install` automatically (pnpm lockfile at repo root). If the site previously served `react-kit-demo`, remove any `/* → /index.html` SPA redirect from the Netlify UI — it breaks Docusaurus static routes.
